## 9. Logs after the launching terminal closes

Each case types the command into an interactive `zsh -f -i` on a new pty, waits 2 s, then closes the pty (the shell receives SIGHUP, as when a terminal window is closed). Then one request is made from outside and the logs are read.

| Case | still serving after close | where the log is | request after close in log |
|---|---|---|---|
| A0 plain `&` | no | the closed terminal (lost) | - |
| A nohup | yes | `a.log` (path chosen at launch) | yes |
| B taba | yes | `taba logs bench/web` | yes |
| C docker | yes | `docker logs ID` | yes |
